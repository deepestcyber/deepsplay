# 3. Application name deepsplay

Date: 2026-11-06

## Status

Accepted

## Context

The outline calls the project "display app", which is a description, not a
name. Code, repository, release and docs need one fixed name.

## Decision

The application is named **deepsplay**: a display application by and for
Deep Cyber ([www.deepcyber.de](https://www.deepcyber.de)), "deep" + "display".

- Written in lowercase in text: deepsplay.
- OTP application `:deepsplay`, module namespace `Deepsplay`.

## Consequences

- Repository, release, container image and docs use this name.
- "Display app" in older documents means deepsplay.
